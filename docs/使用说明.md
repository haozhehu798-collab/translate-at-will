# 快捷翻译 · 使用说明

> 一个在 Windows 上**任何界面**都能用的全局翻译 + AI 提问小工具。
> 看文献、刷网页、用 AI、读 PDF……遇到不认识的英文，**选中后按一个快捷键**，结果立刻出现在鼠标旁边；
> 遇到扫描版 PDF、图片里**选不中**的文字，能**框选屏幕做 OCR 识别翻译**；
> 想让 AI 详细讲解某个词、某段话，再按一个快捷键，**AI 对话窗**直接回答。
> 单个 exe 文件，**不用装 Python、不用安装**，拷贝到任何 Windows 电脑都能直接用。

---

## 一、功能一览

| 功能 | 快捷键（默认） | 说明 |
| --- | --- | --- |
| **划词翻译** | `Ctrl + Alt + E` | 选中任意英文单词/短语/句子后按下，即出翻译 |
| **截图 OCR 翻译** | `Ctrl + Alt + S` | 框选屏幕一块区域，识别其中文字并翻译 |
| **AI 提问** | `Ctrl + Alt + A` | 选中内容后按下，在 AI 对话窗里详细讲解/翻译/润色 |
| 中英互译 | 自动判断 | 英文→中文，中文→英文，无需手动切换 |
| 单词多来源释义 | 弹窗内 | 专业释义、缩写全称、网络释义、词典全部列出 |
| 单词音标与朗读 | 弹窗内 | 显示英式/美式音标，点小喇叭听发音 |
| 译文自动复制 | 默认开启 | 翻译后译文已在剪贴板，可直接 `Ctrl+V` |
| 查词历史 | 自动记录 | 查询保存在程序同目录 `history.csv` |
| 开机自启 | 可开关 | 开机后在后台托盘待命，无需每次手动打开 |

## 二、系统要求

- **操作系统**：Windows 10 或 Windows 11（64 位）。
- **网络**：翻译和 AI 提问需要联网；OCR 识别本身**不需要联网**（用 Windows 自带识别引擎）。
- 无需安装 Python 或任何运行环境，exe 已内置全部所需组件。

---

## 三、快速上手

1. **双击 `快捷翻译.exe`** 启动。
   - 程序不弹主窗口，而是在屏幕右下角**系统托盘区**（时钟附近）出现一个蓝色小图标。
   - 图标被折叠时，点托盘区的小箭头 `^` 即可看到。
2. 在任意软件里（浏览器、Word、PDF 阅读器、AI 网页……）**选中英文单词或句子**。
3. 按下 **`Ctrl + Alt + E`**，鼠标旁边立刻弹出译文。

> 程序会一直在后台托盘待命，不占任务栏、不打扰你。

## 四、图形设置窗（推荐，所有设置都在这里改）

**双击托盘图标**，或右键托盘图标选 **“打开设置”**，即可打开图形设置窗。窗口分四块：

### 1）快捷键
- 每一行显示当前快捷键，点右侧 **“录制”**，按钮变成“请按键…”，此时**直接按下你想要的组合键**（例如 `Ctrl + Alt + Q`）即可自动保存并重绑。
- 只按了 `Esc` 或单独的 Ctrl/Alt/Shift 会被判定为无效，不会覆盖原快捷键。
- 建议选一个**不与其他软件冲突**的组合键。

### 2）百度翻译官方 API（可选）
- 填 APP ID 和密钥后，长句翻译会优先走百度官方接口（申请方法见第八节）。留空则用内置免费通道。

### 3）AI 助手（OpenAI 兼容）
- **服务商**下拉：预置了 **DeepSeek、豆包(火山方舟)、OpenAI、自定义**，选择后自动填好接口地址。
- 填 **API Key** 和 **模型 Model**（豆包需填接入点 `ep-xxx`），即可使用 AI 提问。
- **专业领域（可选）**：例如填“安全工程/煤矿热动力”。**仅当问题确实与该领域相关时** AI 才会参考，日常无关问题按普通 AI 正常回答、不强行靠拢；留空也完全可以。
- 各服务商 Key 的免费/低价申请方法见第九节。

### 4）常规
- 译文自动复制、开机自动启动、保存查词历史的开关；
- **发音偏好**：美音 / 英音；
- **OCR 语言**：`en`（英文）/ `zh-Hans-CN`（中文）。

改完点右下角 **“保存”** 立即生效；点“取消”放弃。

## 五、三种使用方式

### 方式 1：划词翻译（最常用）　`Ctrl + Alt + E`
适用于**能被鼠标选中**的文字。
1. 用鼠标拖选要查的英文（单词、短语、整句、整段均可）。
2. 按 `Ctrl + Alt + E`，鼠标旁弹出结果窗。
3. **选中多行或整段时，会逐行翻译并按“原文行 → 译文行”对照显示**：原文行以灰色小字在上、对应译文在下，原文的空行保留为段落间隔，每句译文一目了然，不会挤成一团；自动复制的译文同样保留换行，粘贴后依旧分行。

### 方式 2：截图 OCR 翻译　`Ctrl + Alt + S`
适用于**选不中**的文字：扫描版 PDF、图片、论文截图、视频画面、禁止复制的软件，以及**右键菜单、下拉菜单等一按其他键就消失的弹出界面**。
1. 让要查的内容（或弹出菜单）显示在屏幕上。
2. 按 `Ctrl + Alt + S`：程序在按键的**一瞬间就把整屏画面“冻结”成一张静态图**（快捷键被程序拦下、不会传给菜单，所以菜单不会关闭），随后在这张冻结图上框选。
3. **按住左键拖框**框住文字——**框内保持清晰、框外压暗**（与微信截图一致），松开即自动识别翻译；按 `Esc` 或右键可取消。
4. 截图区域里若有**多行文字**，识别后同样会**逐行翻译并按“原文行 → 译文行”对照显示**（系统 OCR 默认会把多行合并成一行，本工具已自动按行还原，不会挤成一团）；长段落还可点“AI 精译”升级。

> 因为是“先冻结、再框选”，像 Zotero 齿轮菜单、软件右键菜单这类“一碰就消失”的界面也能被完整截下来翻译。
> OCR 由 Windows 自带引擎完成，**识别过程不联网、不上传图片**。

### 方式 3：AI 提问　`Ctrl + Alt + A`
1. 选中想深入了解的词、短语或一段话（**不选也可以**，会打开空白 AI 窗，直接自由提问）。
2. 按 `Ctrl + Alt + A`，弹出 **AI 对话窗**；若选中了文字，会自动做“详细解释”。
3. 顶部三个快捷动作：**详细解释 / 翻译并讲解 / 润色改写**。
4. **底部输入框可以像普通 AI 一样自由提问，不限于上面三个动作**：点一下输入框即可打字，**回车发送、Shift+回车换行**；每次回答完，光标会自动回到输入框，方便连续追问。
5. 推理类模型会先实时显示“思考过程”，随后给出回答；文字按小批量刷新，不会卡顿。
6. AI 默认**简洁直接、先给答案**，不客套、不铺垫、不长篇大论；设置里的“专业领域”只在问题确实相关时才参考，日常随机问题就像普通 AI 一样正常回答，不会硬往专业上靠。

> 尚未配置 AI 时，窗口会提示并提供 **“打开设置”** 按钮，点它即可去填 Key。

## 六、翻译结果窗与“多来源释义”

查**单词或缩写**时，结果窗会**把能查到的含义全部列出**，方便你结合专业自行判断，分组如下：

- **专业释义 · 来源于论文库**：按学科分类（计算机、医药、物理、化学……），并附英文全称。
- **词典释义（含缩写全称）**：词性、常规释义；缩写会给出英文全称，例如 `abbr. …（Training and Enterprise Council）`。
- **网络释义**：该词在网络上的全部常见译法。
- **百科**（部分普通单词有）：简明背景介绍。
- **百度翻译官方 / 百度词典**：配置官方 Key 后额外提供。

> 例如查缩写 **TEC**，会同时列出“东京电气公司、胸腺上皮细胞、培训和企业理事会、东芝、柠檬酸三乙酯、典型用电量、**热电制冷器(Thermoelectric Cooler)**”等全部含义，
> 你要的专业答案一定在其中，而不是只给一个通用结果。

结果窗还能：
- 点英式/美式音标旁的**小喇叭**听发音；
- 译文**已自动复制**，到任意处 `Ctrl+V` 粘贴；
- 关闭：点窗以外任意位置、按 `Esc`、或点右上角 `×`。

**AI 精译 / AI 详解（配置了 AI 后，结果窗右下角出现按钮）**
- 翻译**长句或整段**后显示 **“AI 精译”**：点一下用 AI 大模型重新翻译，**语序更自然、专业术语更准确**（尤其适合论文长难句、专业段落）；多行内容仍保持逐行对照，精译结果会更新复制与历史。日常用免费通道秒出即可，遇到拿不准或要求高的句子再点它升级。
- 查**单词或缩写**时显示 **“AI 详解”**：点一下打开 AI 对话窗，自动结合语境讲清它的含义、用法和专业背景。
- 两个按钮复用你在设置里配置的 AI（如 DeepSeek），仅在点击时调用，消耗极少。

> 翻译质量由高到低：**AI 精译（最通顺、术语最准）＞ 百度官方 API（可选）＞ 内置免费通道（秒出）**。免费通道负责即时，AI 精译负责高质量。

## 八、【可选】配置百度官方翻译（免费）

默认已内置**免注册**翻译通道，开箱即用。若想要更稳定的长句翻译，可免费申请百度官方密钥（约 2 分钟）：

1. 打开 **`https://fanyi-api.baidu.com/`**，用百度账号登录，进入“管理控制台”。
2. 注册为**个人开发者**；只用标准版时，实名认证可“跳过”。
3. 点“立即开通”，选“通用翻译 API · **标准版**”（标准版不限量、QPS=1、免费、无需认证）。
   - 表单若有 **“服务器地址 / IP 白名单”，务必留空**，否则换电脑/换网络会报“未授权”。
4. 在“开发者信息”页拿到 **APP ID** 和 **密钥**。
5. 打开本工具设置窗，填到“百度翻译官方 API”一栏，保存。

**密钥只保存在本机 `config.ini`，不会上传给本工具作者。**

## 九、【可选】配置 AI（DeepSeek / 豆包 / OpenAI）

AI 功能采用通用的 **OpenAI 兼容接口**，在设置窗“AI 助手”里配置。三家常见选择：

### DeepSeek（推荐，性价比高）
1. 打开 **`https://platform.deepseek.com/`**，注册登录。
2. 左侧 **“API keys” → “创建 API key”**，复制保存（只显示一次）。
3. 账户需有少量余额（按量付费，价格很低，新用户常有赠送）。
4. 在本工具选服务商 **DeepSeek**，粘贴 Key；模型默认 `deepseek-chat`，保存。
- 接口地址：`https://api.deepseek.com/v1`

### 豆包（火山方舟）
1. 打开火山方舟控制台 **`https://console.volcengine.com/ark`**，注册并开通服务。
2. **“在线推理”里创建一个“推理接入点”**，选择要用的模型（如 Doubao 系列），创建后得到接入点 ID，形如 `ep-2026xxxxxx-xxxxx`。
3. 在 **“API Key 管理”** 里创建 API Key。
4. 在本工具选服务商 **豆包(火山方舟)**，粘贴 Key，**模型一栏填接入点 `ep-xxx`**，保存。
- 接口地址：`https://ark.cn-beijing.volces.com/api/v3`

### OpenAI
1. 打开 **`https://platform.openai.com/`**，登录后在 **“API keys”** 创建 Key（需可正常访问 OpenAI）。
2. 在本工具选 **OpenAI**，粘贴 Key；模型默认 `gpt-4o-mini`，保存。
- 接口地址：`https://api.openai.com/v1`

### 自定义 / 其他兼容服务
若使用其他 OpenAI 兼容服务（本地大模型、第三方中转等），选 **自定义**，手动填写接口地址、Key、模型即可。

> 所有 Key 仅保存在本机 `config.ini`。AI 对话内容会发送给你所选的服务商，这是在线 AI 所必需的。

## 十、【可选】安装英文 OCR 语言包（识别更准）

若系统无英文 OCR 包，程序会用中文引擎“兼容识别”英文，安装英文包后更准：

1. 打开 **设置 → 时间和语言 → 语言和区域**。
2. “添加语言”，搜索并选 **英语(美国)**。
3. 勾选 **“光学字符识别(OCR)”**，安装；无需重启，重新按 `Ctrl+Alt+S` 即可。

> 识别中文时，在设置窗把 OCR 语言改为 `zh-Hans-CN`。

## 十一、查词历史

- 每次查询（原文 + 译文 + 时间）追加到程序同目录 **`history.csv`**，可用 Excel 打开（中文不乱码）。
- 托盘菜单“查看历史记录”可快速打开；文件过大时自动只保留最近约 1500 条。
- 不想要历史：在设置窗关闭“保存查词历史”。

## 十二、分享给朋友 / 换电脑使用（通用性）

本工具**绿色便携**：

1. 把整个文件夹拷贝走（至少含 `快捷翻译.exe`），建议同目录放：
   - `快捷翻译.exe`、`使用说明.md`（可选）；
   - `config.ini`、`history.csv` 可选，不带会自动重新生成。
2. 在新电脑**双击 exe** 即可，**无需装 Python、无需运行库、无需管理员权限**。

提示：
- exe 可放任意目录（桌面、文档、U 盘），也可右键“发送到桌面快捷方式”。
- 填了 Key 的 `config.ini` 一起拷走，新电脑直接沿用（百度 IP 白名单留空正是为此）。
- 设置开机自启后，请不要移动 exe 位置（自启记录的是路径，移动后需重新勾选）。

## 十三、常见问题（FAQ）

**Q：一定要一直开着 exe 吗？**
A：快捷键靠后台驻留程序响应，**用的时候需在后台运行**（托盘有图标）。它占用很小、不弹窗，建议开机自启；彻底“退出”后快捷键不生效，重新双击即可。

**Q：按快捷键没反应？**
A：依次检查：①托盘是否有图标；②划词模式是否先选中了文字；③快捷键是否与其他软件冲突（在设置窗重新录制一个）；④上一个结果窗是否仍在处理。

**Q：AI 提问没反应 / 提示未配置？**
A：AI 需要先在“设置 → AI 助手”填好**接口地址、Key、模型**三项；按第九节申请。

**Q：SmartScreen 提示“未知发布者”？**
A：个人开发、未购买数字签名证书的常见提示，不代表风险，选“更多信息 → 仍要运行”。源码随附可查。

**Q：PDF 里查不了？**
A：能选中字的 PDF 用 `Ctrl+Alt+E`；扫描/图片版选不中字，用 `Ctrl+Alt+S`。

**Q：翻译或 AI 结果不理想？**
A：单词/缩写已把多来源含义全部列出，可自行挑选；长句可配置百度官方接口；AI 可在设置窗填写“专业领域”，回答更贴合你的专业。

**Q：内容会被记录或上传吗？**
A：仅在你开启“历史记录”时写到本机 `history.csv`；翻译/AI 需把文字发送给相应服务商（在线服务所必需）；OCR 在本机完成、不上传图片。
